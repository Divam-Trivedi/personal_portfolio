Getting started

Download, open the app, and it launches in your browser. Add an API key in the settings, pick a model and start chatting. To quit, use the power icon at the bottom of the sidebar.

Seeing a security warning on first launch?

The app isn't code-signed yet, so your system asks you to confirm it once. On macOS, right-click the app, choose Open, then choose Open again. On Windows, choose More info, then Run anyway.
